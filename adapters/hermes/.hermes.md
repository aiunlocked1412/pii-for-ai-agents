# PII for AI Agents

This project includes portable Project Intelligence Index workflows.

- When asked to initialize, bootstrap, create, or set up PII, read `.pindex/core/init.md` and execute it.
- When asked to update, refresh, synchronize, or maintain PII, read `.pindex/core/update.md` and execute it.
- Before meaningful work, if `.project-intel/INDEX.md` exists, read it and `.project-intel/CURRENT.md`, then load only relevant knowledge.
- Original project files remain the final source of truth.
